# PromptBox

**本地优先的 AI 提示词管理与批量生成工具**

PromptBox 是一个基于 Web 的提示词管理工具，旨在帮助用户将常用提示词整理为可复用模板，通过变量填写和实时预览减少重复输入，提高学习、写作与设计等任务的效率。

## V1.0 功能

- **模板管理**：新建、编辑和删除提示词模板。
- **模板搜索**：按模板名称、分类和用途搜索。
- **变量识别**：自动识别 `{{变量名}}` 格式的占位符。
- **动态填写**：根据模板变量生成输入框。
- **实时预览**：填写变量时即时更新最终提示词。
- **复制结果**：复制原始模板或填写变量后的完整提示词。
- **本地存储**：使用 IndexedDB 在浏览器本地保存模板数据。

## 技术栈

- Next.js
- React
- TypeScript
- Tailwind CSS
- Dexie.js / IndexedDB

## 环境要求

- Node.js
- npm

## 本地运行

克隆项目后，在项目根目录执行：

```bash
npm install
npm run dev
```

打开浏览器访问 `http://localhost:3000`。

promptbox/

## 数据存储说明

V1.0 使用浏览器 IndexedDB 保存模板。数据保存在当前浏览器环境中，不会因为上传项目到 GitHub 而自动同步到其他设备。

清除浏览器本地数据库可能导致用户数据丢失，请在操作前做好备份。

## 版本规划

V1.0 聚焦模板管理、变量填写、实时预览和提示词复制。批量生成、生成历史、数据备份与恢复、云端同步及 AI 模型 API 调用可作为后续版本的扩展方向。
